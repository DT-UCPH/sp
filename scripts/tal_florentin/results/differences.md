# Differences between the running texts of Tal & Florentin (2024) and the CACCHT Samaritan Pentateuch

This file lists every difference between the consonantal Hebrew text printed in Moshe Florentin and Abraham Tal, *The Samaritan Pentateuch: An English Translation with a Parallel Annotated Hebrew Text* (Open Book Publishers, 2024, https://doi.org/10.11647/OBP.0415), and the CACCHT Text-Fabric dataset of the Samaritan Pentateuch (https://github.com/DT-UCPH/sp, https://doi.org/10.5281/zenodo.7734632). It is generated by `compare.py`; do not edit it by hand.

## How to reproduce

From the folder `scripts/tal_florentin` of the CACCHT repository (https://github.com/DT-UCPH/sp) at commit `5c368a7`, with the T&F PDF (free download via the DOI above) saved there as `tal_florentin_SP.pdf` (the PDF is not in the repository):

```
pip install pymupdf text-fabric
python extract_tf.py tal_florentin_SP.pdf results/tf_verses.json
python extract_caccht.py ../../tf/7.4.1 results/caccht_verses.json
python compare.py results/tf_verses.json results/caccht_verses.json results
```

Check that the SHA-256 of the PDF matches the value above. The same output files (`differences.md`, `differences.tsv`, `versification.tsv`) should then be produced.

## Method

1. **T&F.** The Hebrew running text is taken from the PDF by font: SBL Hebrew 13.5 pt (text), 9 pt (verse numbers), bold 13.5 pt (chapter numbers) and bold 18 pt (book titles). Footnotes, running heads and the English translation are ignored. Words are ordered right to left by the position of their characters on the page. Punctuation and paragraph marks (`:>— —`) are dropped. Colouring (red = difference from MT) is ignored. Sub-verse numbers ([א]18, [ב]18 …) are counted with the main verse; the Hebrew letters numbering the commandments in the Decalogue are not text.
2. **CACCHT.** For every verse, the `g_cons_utf8` values of the `word` nodes are concatenated with their `trailer`. Morphemes such as ו, ה, ב are separate word nodes in CACCHT, so one graphic word can consist of several nodes. Shin/sin dots are removed.
3. **Alignment.** The graphic words of each chapter are aligned with Python’s `difflib.SequenceMatcher` (no autojunk). Final and non-final letter forms count as equal, because CACCHT writes compound names as e.g. `BN_<MJ` → בנ עמי. Because alignment is per chapter, different verse division does not create false textual differences; it is listed separately at the end.
4. **Classification.** Every non-matching stretch is classified with the rules below, in this order. The types are mechanical, not a philological judgement.

### Types of difference

| Type | Definition |
|---|---|
| plene/defective | The words differ only in a word-internal mater lectionis ו or י. |
| conjunction waw | One edition has the conjunction ו prefixed, the other not. |
| article he | One edition has a prefixed ה (article or interrogative), the other not. |
| guttural interchange | Same length; the words differ only in the gutturals א/ה/ח/ע. |
| aleph plus/minus | The words differ only in the presence of a (non-initial) א. |
| final he/yod | The words differ only in a final ה versus final י (after removing internal matres). |
| word division | Same letters, divided differently into words (e.g. בהר גריזים / בהרגריזים). |
| plus T&F | Word(s) present only in Tal & Florentin. |
| plus CACCHT | Word(s) present only in CACCHT. |
| colophon (T&F only) | Scribal book-end colophon (…קצים…) printed by T&F, not part of CACCHT. |
| probable CACCHT error | Reading in CACCHT that looks like a data-entry error. |
| other | Any other difference (morphology, different lexeme, metathesis, several words, …). |

### How to read the tables

- **CACCHT ref**: book chapter:verse in CACCHT; **T&F ref**: verse number under which the words stand in T&F, with the printed page on which that verse begins.
- **CACCHT word node(s)**: the Text-Fabric `word` nodes that make up the CACCHT reading. For a word that only T&F has, “after *n*” gives the CACCHT word node after which the T&F words stand.
- **Verse node**: the CACCHT `verse` node. In Text-Fabric, `T.text(n)` or `F.g_cons_utf8.v(n)` shows the text of a node.
- — = no text in that edition.
